# construction-docx-style

建筑工程施工方案 / 标书 docx 的 **01~25 命名样式体系**自动注入与改排工具。可作为 [ZCode](https://zcode.ai) 技能使用，也可作为独立 Python 脚本运行。

把一份手工排版的施工方案 / 投标文件 docx 自动改排为规范化样式体系：多级标题自动编号（第一章 / 1.1 / 1.1.1 / 1.1.1.1）、条目自动编号（1、/ 1））、表题图题自动编号（表 1.1-1 / 图 1.1-1）、正文起点识别、章间分页、遗留直接格式清洗、重置模式。

## 功能特性

- **样式与编号注入**：向目标 docx 注入 20 个命名样式（01章~25表格顶头）与九级共享多级编号（冲突自动改号）；
- **自动识别改排**：按可见文本模式与位置规则识别段落角色——章（第X章 / 1 ）、节（1.1）、条（1.1.1）、款（1.1.1.1）、条目（1、/ 1））、表题、图题、图片、正文、表内文字——套用对应样式并剥离手工序号；
- **正文起点识别**：首个章级标题之前的前置页（封面、签署页、修订记录、目录）原样保留、不参与改排；
- **章间分页**：每个章标题自动段前分页（每章另起一页）；
- **先清格式、再套样式**：清除原文件遗留的直接排版（字体/字号/缩进/行距/对齐），外观完全由命名样式接管（表格与正文保留加粗）；
- **重置模式**：对已套过改造版体系样式的文档，清除旧样式定义，回归标准体系；
- **结构保护**：分节符（sectPr）、书签、既有编号定义硬保护，不改坏文档。

## 环境要求

- Python 3.8+（仅标准库，无第三方依赖）
- 目标文件为 .docx（OOXML）

## 安装

**作为 ZCode 技能**：将本目录复制到技能目录之一：

```bash
# 用户级（所有项目可用）
mkdir -p ~/.agents/skills && cp -r construction-docx-style ~/.agents/skills/
# 或项目级
mkdir -p .agents/skills && cp -r construction-docx-style .agents/skills/
```

**作为独立脚本**：直接使用 `scripts/apply_styles.py`，或将其与 `assets/` 一并拷贝到任意位置。

## 使用

```bash
# 先预览识别报告（不写文件）
python scripts/apply_styles.py "施工方案.docx" --dry-run

# 正式改排（输出 施工方案_styled.docx，不覆盖原件）
python scripts/apply_styles.py "施工方案.docx"

# 常用选项
python scripts/apply_styles.py "施工方案.docx" \
    --body-start "编制依据" \        # 显式指定正文起点标记
    --no-chapter-breaks              # 关闭章间分页
```

### 全部选项

| 选项 | 说明 |
|---|---|
| `--dry-run` | 仅输出识别报告，不写文件 |
| `--in-place` | 原地覆盖目标文件 |
| `--no-tables` | 跳过表内文字改排 |
| `--keep-caption-numbers` | 保留表/图题手工编号（该类段落不改排） |
| `--body-start "文本"` | 显式指定正文起点标记文本 |
| `--restyle-front` | 前置页（封面/签署页/修订记录）也参与改排 |
| `--no-chapter-breaks` | 不在章标题前插入分页符 |
| `--keep-direct` | 保留原文件直接排版（默认先清除遗留直接格式再套样式） |
| `--reset-styles` | 清除目标已有体系样式（定义与格式），按标准样式重新排版 |

## 样式体系（摘要）

| 样式 | 用途 | 要点 |
|---|---|---|
| 01章 | 章标题 | 黑体 16pt 居中，自动编号"第%1章"（第一章），段前分页 |
| 02节 / 03条 / 04款 / 05点 | 二~五级标题 | 黑体 14pt，自动编号 1.1 / 1.1.1 / 1.1.1.1 / 五级 |
| 06滴 / 07目 | 条目 | 宋体 12pt，自动编号"1、"/"1）" |
| 08正文 | 正文段 | 宋体 12pt，首行缩进 2 字符，1.5 倍行距 |
| 09表 / 10图 | 表题/图题 | 自动编号"表%1.%2-%8"/"图%1.%2-%9"，09表 keepNext |
| 11表内居中 / 12表内左对齐 | 表内文字 | 10pt；**12 为表内默认**（无首行缩进） |
| 13图片 | 插图 | 居中 |
| 14~25 | 副标题/辅助说明/投标表格等辅助样式 | 按需使用 |

完整定义见 `references/style-spec.md`。

## 已知边界

- 标题手工编号后需跟空格；"1.标题"式点号紧跟暂不识别（需先归一化）；
- 骨架最深五级（05点），更深层级落为正文；
- 经 Word 保存的文档，目录条目可能带悬空样式引用——脚本跳过不动，Word 中更新目录域（F9）后自动消除。

## 来源

样式与编号定义提取自建筑工程施工总承包标书通用母版，与常见装饰装修施工方案模板的样式体系同源（后者止于三级标题、表图题手工编号）。技术细节见 `references/style-spec.md`。
